System Diagnostics & Troubleshooting Playbook

            
Pre-flight checks and quick health diagnostic routines for local development and production.

          

          
        


        

          

            

               1. Backend API Health
            

            
Checks if ASP.NET Core Kestrel is listening on port 5010/5000 and accepting requests.

            

              curl http://localhost:5010/health
            

          


          

            

               2. SQL Server Connection
            

            
Tests connection string validity, credentials, and pending database migrations.

            

              dotnet ef database update --dry-run
            

          


          

            

               3. LIS Socket Ports
            

            
Verifies that ports 8004, 10001, and 10002 are not locked or blocked by firewall.

            

              netstat -ano | findstr "10001"
